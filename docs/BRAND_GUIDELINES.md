# ChessVerse Brand Guidelines

## 1. Brand Elements

### Name & Wordmark
- **Name**: ChessVerse (CamelCase, capital C and V, no spaces).
- **Tagline**: *Play. Watch. Improve.*

### Official Logo Variants
1. **Full Logo**: `♟ ChessVerse`
   - Use in: Desktop header, marketing cards, splash screens, documentation.
2. **Compact Logo**: `♟`
   - Use in: Mobile header, browser favicon, notification icons, compact avatars.
3. **Wordmark**: `ChessVerse`
   - Use in: Editorial articles, press releases, legal disclaimers.

```
Clear Space Rule:
      ┌───────────────────────────────┐
      │          [ min 8px ]          │
      │   [8px]  ♟ ChessVerse  [8px]  │
      │          [ min 8px ]          │
      └───────────────────────────────┘
```

### Prohibited Logo Treatments
- ❌ Never add drop shadow glows, neon outlines, or neon filters.
- ❌ Never animate the logo with continuous rotation or spinning.
- ❌ Never distort, stretch, or alter the aspect ratio.
- ❌ Never place arbitrary icons or text flush against the mark without clear-space.

## 2. Copywriting Style Guide

ChessVerse communicates with the confidence, clarity, and precision of a Grandmaster.

| Approved Copy | Rejected Copy | Rationale |
| :--- | :--- | :--- |
| **"Play with friends"** | *"Unlock your ultimate social chess potential"* | Direct and honest |
| **"Watch live games"** | *"Experience the next-generation spectator portal"* | No marketing fluff |
| **"Analyze your game"** | *"Revolutionize your chess intellect with AI"* | Plain human speech |
| **"Invite a friend"** | *"Leverage viral multiplayer peer networks"* | Authentic connection |
| **"Something went wrong"** | *"Fatal system exception code 0x500"* | Reassuring, clear action |

---

## 3. Responsive Identity

- **Desktop (>= 1024px)**: Full AppSidebar with persistent brand mark, primary navigation links (Play, Watch, Puzzles, Friends), profile pill, and settings.
- **Tablet (768px – 1023px)**: Compact sidebar or collapsible drawer maintaining direct access to live games and matchmaking.
- **Mobile (< 768px)**: Sticky bottom navigation bar with high-contrast icon + label pairs and 44px minimum touch targets.

---

## 4. Free-Only Product Promise
ChessVerse is architected as an entirely free platform:
- Every feature, theme, board style, piece set, Stockfish 18 deep engine review, and tactical puzzle collection is unlocked for all registered users and guests.
- There are no subscriptions, pro upgrades, checkout flows, or locked badges anywhere in the product.
